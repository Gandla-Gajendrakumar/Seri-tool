# Decision log

Decisions I made without asking, because they don't change cost, farmer experience or scope.
Newest last. Fixed decisions from the brief are in `requirements.md` §2 and are not repeated here.

| # | Date | Decision | Reason |
|---|---|---|---|
| D-001 | 2026-11-21 | Build system: **PlatformIO** with two environments: `native` (PC unit tests, Unity framework) and `esp32` (Arduino framework, board `esp32dev`, i.e. DevKitC WROOM-32). | One tool builds both the testable pure-logic code and the target firmware. Arduino gives ready drivers for SHT31, DS3231, OLED and SD. ESP-IDF APIs stay reachable for OTA and watchdog. |
| D-002 | 2026-11-21 | **KiCad 9.0.9** (from the official KiCad PPA), not Ubuntu's KiCad 7.0. | KiCad 7's command-line tool cannot run the electrical rules check (ERC) or design rules check (DRC). The phase 4 gate needs both from the command line. |
| D-003 | 2026-11-21 | Created a personal cloud environment **"Seri-tool"** for this repo. Its allowed hosts: PlatformIO registry + its download mirror, Espressif downloads, wokwi.com, Launchpad (KiCad PPA). | The default environment blocked the PlatformIO registry and the KiCad PPA. |
| D-004 | 2026-11-21 | ngspice 42 (Ubuntu), CadQuery 2.8.0 (pip), wokwi-cli 0.29.1 (static binary from its GitHub release; it isn't published on npm). | Latest available through allowed channels. All exercised by `tools/check_toolchain.sh`. |
| D-005 | 2026-11-21 | Time zone fixed at **IST (UTC+5:30)**. Timestamps are stored in UTC on SD and over MQTT, and shown and printed in IST. | India has one time zone and no daylight saving. UTC storage avoids ambiguity in the cloud. |
| D-006 | 2026-11-21 | Raw SHT31 reads every 6 s; the median of 5 forms the 30 s sample. | Spreads the 5 reads across the window, so the median rejects short spikes (e.g. a door opening) rather than just electrical noise. |
| D-007 | 2026-11-21 | Every SMS template must fit one segment: 70 UCS-2 characters for Indian scripts, 160 for English. Enforced by a unit test. | Multi-part SMS can arrive out of order or partially on basic phones, and costs more. |
| D-008 | 2026-11-21 | Debounce mains-fail / mains-return by 2 minutes. | Rural supply flickers often. Without debounce, this alone would flood SMS (violates "must not happen"). |
| D-009 | 2026-11-21 | Stage changes clear active events silently (log + print only). | A farmer changing the stage should not receive a burst of "recovered" texts. |
| D-010 | 2026-11-21 | SMS cap counters and settings are kept in ESP32 NVS flash. | A reboot loop must not reset the cap and cause a flood. |
| D-011 | 2026-11-21 | OTA uses ESP32 dual app partitions with signed images and rollback. | The standard, proven ESP32 mechanism. A bad update must never brick a unit in a remote shed. |
| D-012 | 2026-11-21 | **Hard ceiling of 20 SMS per number per day** on top of the 6-repeat cap. Every first alert reserves room for its own recovery text. | The repeat cap alone does not bound total texts on a bad day (power flicker + temperature flapping + sensor). Reserving room means a "back to normal" text is never blocked, which the brief requires. Proven by a 3-day flapping test. |
| D-013 | 2026-11-21 | The same kind of event starting again within **60 min** (not 10 min, as drafted) of ending is sent as a repeat and counts against the cap. | Temperature hovering near a band edge would otherwise produce a free "first" alert every ~6 minutes. |
| D-014 | 2026-11-21 | Repeats only for climate and sensor-fault events. Recovery SMS only for climate, sensor-fault and power-cut ("power back") events. Paper, SD, clock and low-battery events send one SMS. Their recovery is printed and shown, not texted. | These are the events the farmer must act on, or must know have ended. Fewer texts keeps them meaningful. |
| D-015 | 2026-11-21 | Temperatures and humidity are handled as integers in tenths (25.3 C = 253). | Exact comparisons and hysteresis, with no floating-point surprises at band edges. |
| D-016 | 2026-11-21 | SMS from unregistered numbers get no reply. Owner claim by device PIN, locked after 5 wrong PINs per day. | Avoids paying for replies to spam and blocks PIN guessing. The PIN lets a farmer who lost their phone take ownership again. |
| D-017 | 2026-11-21 | Indian-language SMS use UCS-2 (70 characters), not the 3GPP "national language shift tables". | Shift-table support on feature phones is inconsistent; UCS-2 works everywhere. Every message is tested to fit one segment with ≥3 characters spare. |
| D-018 | 2026-11-21 | Summaries held while on battery are kept (up to 7) and printed oldest-first, marked late, when mains returns. | Brief: on battery, print event lines only. Nothing is lost. |
| D-019 | 2026-11-21 | Low-battery alert only while running on battery, after 60 s below threshold. | A discharged battery charging on mains is not an emergency. 60 s ignores voltage dips during modem transmit bursts. Threshold (3.40 V) is provisional until the cell datasheet check in phase 4. |
| D-020 | 2026-11-21 | Wi-Fi SMS command `30 <name> <password>`: the name cannot contain spaces; the password can contain anything. | Simple digit-led command for installers. Networks with spaces in the name can be set with the buttons (phase 2). |
| D-022 | 2026-11-22 | Spinning stage name in Indian languages is the single word for "cocoon" (कोया / గూడు / ಗೂಡು); command `11 6` selects it. | Longer phrases pushed the worst-case alert SMS to 69-72 characters. The one-word form keeps ≥3 characters spare. Wording is in the native-speaker review list. |
| D-021 | 2026-11-21 | Stage profile citations added to `stage_profiles.inc`. **No values changed.** | All five brief values were confirmed in Central Silk Board / CSRTI documents. |
| D-023 | 2026-11-22 | **Wokwi simulations run in GitHub Actions**, with `WOKWI_CLI_TOKEN` as an encrypted repository secret (product-owner choice). | From this cloud machine, wokwi-cli ignores the HTTPS proxy. A local relay (`tools/wokwi_relay.mjs`, via `WOKWI_CLI_SERVER`) fixes that: it reached Wokwi and got "Unauthorized" with a dummy token. But when the token is injected as a network secret, the proxy rewrites the websocket upgrade and Wokwi's Cloudflare worker returns error 1101. Custom chips still compile here with `wokwi-cli chip compile`. |
